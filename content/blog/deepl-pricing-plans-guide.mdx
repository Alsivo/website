## まず結論：こういう人はこのプラン
- コードで連携したい／自動化したい、かつ月50万文字以内の見込み → まずは「API Free」で試す（無料枠あり）[[5]](https://developers.deepl.com/docs/resources/usage-limits?utm_source=openai)
- コード連携で50万文字を超える／安定運用や見積もり精度を高めたい → 「API Pro」（月額基本＋従量）[[2]](https://support.deepl.com/hc/en-us/articles/360021200939-DeepL-API-plans?utm_source=openai)
- 開発はしないが、個人でしっかり使いたい → 「DeepL Pro（個人）」を検討（最新の提供内容・価格は公式で要確認）[[4]](https://www.deepl.com/en/pro)[[1]](https://support.deepl.com/hc/ja/articles/360019924499-DeepL%E3%81%AE%E3%83%97%E3%83%A9%E3%83%B3%E3%81%AB%E3%81%A4%E3%81%84%E3%81%A6?utm_source=openai)
- 複数人での運用・一括契約や管理が必要 → 「DeepL Pro（Teams/法人向け）」を検討（提供内容は改定があるため最新ページを要確認）[[1]](https://support.deepl.com/hc/ja/articles/360019924499-DeepL%E3%81%AE%E3%83%97%E3%83%A9%E3%83%B3%E3%81%AB%E3%81%A4%E3%81%84%E3%81%A6?utm_source=openai)[[4]](https://www.deepl.com/en/pro)
- まずは試したい／軽い翻訳が中心 → 無料版（ただし入出力上限などの詳細はUIや時期で変動し得るため都度確認）[[4]](https://www.deepl.com/en/pro)

## DeepLの料金プラン全体像
DeepLの課金体系は大きく以下に分かれます。
- 無料版（Web/アプリでの基本利用。具体的な上限はUIや時期で変動し得る）[[4]](https://www.deepl.com/en/pro)
- DeepL Pro（個人／チーム・企業向けのサブスクリプション）[[1]](https://support.deepl.com/hc/ja/articles/360019924499-DeepL%E3%81%AE%E3%83%97%E3%83%A9%E3%83%B3%E3%81%AB%E3%81%A4%E3%81%84%E3%81%A6?utm_source=openai)[[3]](https://support.deepl.com/hc/en-us/articles/360020600520-Billing-periods?utm_source=openai)
- DeepL API（API Free と API Pro）[[2]](https://support.deepl.com/hc/en-us/articles/360021200939-DeepL-API-plans?utm_source=openai)

API Freeは「月50万文字まで無料」[[5]](https://developers.deepl.com/docs/resources/usage-limits?utm_source=openai)、API Proは「月額の基本料金＋翻訳文字数の従量課金」というモデルです（単価・通貨は地域に依存）[[2]](https://support.deepl.com/hc/en-us/articles/360021200939-DeepL-API-plans?utm_source=openai)。Proの具体的な月額・年額や含まれる機能は地域・言語・表示条件で変わるため、公式のPricing/Proページで最新を確認してください。[[4]](https://www.deepl.com/en/pro)


## 料金の基本ルール：課金単位・支払い・上限の考え方
- 支払いサイクル（Pro系）：月払い／年払いを選択可能。年払いは無料体験終了後に1年分前払い。最短契約期間は1カ月。[[3]](https://support.deepl.com/hc/en-us/articles/360020600520-Billing-periods?utm_source=openai)
- APIの課金単位：API Proは「月額の基本料金＋翻訳文字数の従量課金」。従量単価や通貨は地域に依存し、公式のAPIプラン／Pricingでの確認が必要。[[2]](https://support.deepl.com/hc/en-us/articles/360021200939-DeepL-API-plans?utm_source=openai)
- APIの無料枠：API Freeは「月50万文字まで無料」。具体的な上限・レート制限は開発者ドキュメントの最新値に従う。[[5]](https://developers.deepl.com/docs/resources/usage-limits?utm_source=openai)
- 表示金額の変動：価格の表示は地域・言語・ログイン状態で変わる場合がある。必ず自身の条件で公式ページを再確認。[[4]](https://www.deepl.com/en/pro)


## 個人向けProプランの違いと選び方
個人での本格利用や業務利用を想定するなら、DeepL Pro（個人）を検討します。提供内容や価格は改定されることがあるため、最終的には公式Proページで直接確認してください。[[1]](https://support.deepl.com/hc/ja/articles/360019924499-DeepL%E3%81%AE%E3%83%97%E3%83%A9%E3%83%B3%E3%81%AB%E3%81%A4%E3%81%84%E3%81%A6?utm_source=openai)[[4]](https://www.deepl.com/en/pro)
- 想定ユーザー例：毎日DeepLを使う学生・フリーランサー・担当者など（目安は自身の実利用量から見積もり）
- 支払い：月払い／年払い（年払いは無料体験後に前払い。最短契約1カ月）[[3]](https://support.deepl.com/hc/en-us/articles/360020600520-Billing-periods?utm_source=openai)
- 機能・上限：プラン構成や上限は変更されることがあるため、最新の「プランと価格」を参照のこと。[[1]](https://support.deepl.com/hc/ja/articles/360019924499-DeepL%E3%81%AE%E3%83%97%E3%83%A9%E3%83%B3%E3%81%AB%E3%81%A4%E3%81%84%E3%81%A6?utm_source=openai)

## APIの料金と見積もり方法（FreeとProの違い、手順つき）
- API Free：月50万文字まで無料。[[5]](https://developers.deepl.com/docs/resources/usage-limits?utm_source=openai)
- API Pro：月額の基本料金＋翻訳文字数の従量課金（単価・通貨は地域依存。公式で要確認）。[[2]](https://support.deepl.com/hc/en-us/articles/360021200939-DeepL-API-plans?utm_source=openai)

見積もり手順（API Proの例）
1) 月間の翻訳対象文字数を見積もる（例：1リクエスト平均2,000文字 × 1日50回 × 稼働20日 ≒ 2,000,000文字/月）。
2) 公式のAPI Proの基本料金と従量単価を確認する（地域・通貨により異なる）[[2]](https://support.deepl.com/hc/en-us/articles/360021200939-DeepL-API-plans?utm_source=openai)。
3) 月額見積：月額基本料金＋（見積文字数 × 文字単価）。
4) 上限やレート制限の仕様は開発者ドキュメントの最新情報に従う。[[5]](https://developers.deepl.com/docs/resources/usage-limits?utm_source=openai)


## 無料でできること／できないこと
- 無料版（一般利用）：入出力上限や文書数などの具体値はUIや時期で変動し得ます。利用前に最新の公式ページで確認してください。[[4]](https://www.deepl.com/en/pro)
- API Free：月50万文字まで無料。以降の扱いは開発者ドキュメントの「Usage and limits」に準拠。[[5]](https://developers.deepl.com/docs/resources/usage-limits?utm_source=openai)
- Pro系の詳細（どの機能が含まれるか、どの上限か）は改定があるため、必ず最新の「プランと価格」を参照。[[1]](https://support.deepl.com/hc/ja/articles/360019924499-DeepL%E3%81%AE%E3%83%97%E3%83%A9%E3%83%B3%E3%81%AB%E3%81%A4%E3%81%84%E3%81%A6?utm_source=openai)[[4]](https://www.deepl.com/en/pro)


## どれだけの文字数を使う？業務別・ユースケース別の月間目安と費用感の出し方
以下は概算の出し方（テンプレ）です。実際の料金計算は、Pro/Teamsは公式ページ、APIはAPI Proの単価で置き換えてください。
- テンプレ1：ドキュメント翻訳中心（APIを利用しない場合）
  - 1文書あたりの平均文字数 × 月間文書数 ＝ 月間想定文字数
  - 例：平均4,000文字 × 60本 ＝ 240,000文字
- テンプレ2：Web/アプリ上での日次翻訳
  - 1日の平均翻訳文字数 × 稼働日数 ＝ 月間想定文字数
  - 例：15,000文字 × 20日 ＝ 300,000文字
- テンプレ3：APIでの自動バッチ処理
  - 1ジョブの平均文字数 × 月間ジョブ回数 ＝ 月間想定文字数（API Freeの無料枠50万文字と比較し、超えるならAPI Proの従量を加味）[[5]](https://developers.deepl.com/docs/resources/usage-limits?utm_source=openai)[[2]](https://support.deepl.com/hc/en-us/articles/360021200939-DeepL-API-plans?utm_source=openai)


## 料金を抑える実践テク
- 再翻訳を減らす：確定した原稿は使い回す、文書のバージョン管理で重複翻訳を避ける。
- まとめて処理：小分けよりもまとめて翻訳することでAPI呼び出し回数のオーバーヘッドを抑える（実装側最適化）。
- 用語集や定型フレーズ整備：不要な再修正を減らし、文字数の無駄を抑制。
- 運用ルール：誰がいつ何を翻訳するかを決めて、重複依頼を防ぐ。

## まとめ
- DeepLは「無料」「Pro（個人/Teams）」「API（Free/Pro）」で考えると全体像がつかみやすい。[[1]](https://support.deepl.com/hc/ja/articles/360019924499-DeepL%E3%81%AE%E3%83%97%E3%83%A9%E3%83%B3%E3%81%AB%E3%81%A4%E3%81%84%E3%81%A6?utm_source=openai)[[2]](https://support.deepl.com/hc/en-us/articles/360021200939-DeepL-API-plans?utm_source=openai)
- 料金は、Pro系はサブスクリプション（月/年）[[3]](https://support.deepl.com/hc/en-us/articles/360020600520-Billing-periods?utm_source=openai)、API Proは「月額基本＋文字数の従量」[[2]](https://support.deepl.com/hc/en-us/articles/360021200939-DeepL-API-plans?utm_source=openai)、API Freeは「月50万文字まで無料」[[5]](https://developers.deepl.com/docs/resources/usage-limits?utm_source=openai)。
- ただし、価格とプラン構成は地域・言語・ログイン状態で表示が変わり、改定もあるため、必ず最新の公式ページで確認を。特に旧プラン名や他サイトの金額は鵜呑みにしないでください。[[1]](https://support.deepl.com/hc/ja/articles/360019924499-DeepL%E3%81%AE%E3%83%97%E3%83%A9%E3%83%B3%E3%81%AB%E3%81%A4%E3%81%84%E3%81%A6?utm_source=openai)[[4]](https://www.deepl.com/en/pro)

## よくある質問

### API Freeの無料枠はどれくらいですか？

月あたり最大50万文字まで無料です。上限やレート制限の詳細は開発者ドキュメントの最新情報に従ってください。[[5]](https://developers.deepl.com/docs/resources/usage-limits?utm_source=openai)

### API Proの料金はどのように計算されますか？

「月額の基本料金＋翻訳文字数に応じた従量課金」というモデルです。単価・通貨は地域に依存するため、最新のAPIプラン／Pricingを確認してください。[[2]](https://support.deepl.com/hc/en-us/articles/360021200939-DeepL-API-plans?utm_source=openai)

### 個人向けProは月払いと年払いを選べますか？

はい。月払い／年払いを選べます。年払いは無料体験終了後に1年分前払いで、最短契約期間は1カ月です。[[3]](https://support.deepl.com/hc/en-us/articles/360020600520-Billing-periods?utm_source=openai)

### 価格が人によって違って見えるのはなぜですか？

価格の表示は地域・言語・ログイン状態により変わることがあります。必ず自分の条件で公式ページを再確認してください。[[4]](https://www.deepl.com/en/pro)

### 過去に見たプラン名が今は見つかりません。どうすれば？

DeepLは近年プラン改定があり、過去のプランが統合・停止・条件変更されている場合があります。最新の「プランと価格」を確認してください。[[1]](https://support.deepl.com/hc/ja/articles/360019924499-DeepL%E3%81%AE%E3%83%97%E3%83%A9%E3%83%B3%E3%81%AB%E3%81%A4%E3%81%84%E3%81%A6?utm_source=openai)
